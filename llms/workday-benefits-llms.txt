# Workday Developer Site

> Documentation and API specifications for building on the Workday Developer Site.

This site is a JavaScript single-page application. Do not scrape the HTML shell for documentation content.

To fetch a documentation page as Markdown:
- GET https://developer.workday.com/doc/{docId}.md (doc IDs are listed in the Documentation section below)
- GET https://developer.workday.com/documentation/{docId}.md
- GET https://developer.workday.com/documentation/{docId} with Accept: text/markdown

HTML responses for documentation pages include a Link header: </doc/{docId}.md>; rel="alternate"; type="text/markdown".

Public documentation and API specifications are available without authentication. Console, App Builder, and admin tools require a Workday developer account.
